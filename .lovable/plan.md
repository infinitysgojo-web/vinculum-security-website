# Three restrained scholarly tools

## Goal
Add the three agreed enhancements as compact, optional working layers within existing pages. Preserve the current cream, imperial blue, terracotta, brass, and editorial typography system. Add no new page and no persistent data.

## 1. Methodology: Stakeholder Safeguard & Field Audit Bench
- Place one focused section after “Party-Differentiated Application,” where its safeguards already live.
- Present the seven existing parties as a single selectable review sequence: Children, Youth, Elders, Women, Government, Civil Society, and Ex-Combatants.
- For the selected party, show only its bond focus, practice adjustment, and a short three-part audit: evidence reviewed, affected party heard directly, and independent verification recorded.
- Keep completion local to the current browser session and make reset explicit. Clearly label the output as a field prompt, not certification or a substitute for protection obligations.
- Use a compact mobile selector and a restrained desktop side list so all seven parties are never expanded at once.

## 2. Case studies: Executive Dossier
- Add one quiet “Print executive dossier” action near the case heading, not another content block.
- Create a print-only cover and briefing summary from the case data already on the page: case identity, record, four bond scores, doctrinal finding, practice guidance, transferable takeaway, sources, authorship, canonical URL, and date printed.
- Suppress ordinary navigation and decorative motion in print, preserve readable tables and page breaks, and keep the complete evidence rather than producing a shortened or separate version.
- Use the browser’s print dialog so readers can print or save as PDF without uploads, accounts, or new infrastructure.

## 3. Glossary: Canonical Citation & Lineage
- Add one slim reference bar beneath search with a lineage filter and a “Copy citation” control.
- Group the existing terms into a small set of useful lineages derived from their source sections: Doctrine, Intellectual Traditions, Method & Safeguards, Applied Cases, and Diplomatic Practice.
- Keep the current two-column glossary and search behavior; filtering narrows the same cards rather than adding another display.
- Let each term copy a stable canonical citation containing the term, doctrine title, author, source section, and permanent glossary anchor. Show brief copied feedback without opening a modal.
- Add matching structured metadata for each defined term’s canonical URL and source relationship where the existing schema supports it.

## Density and quality rules
- Only one new primary section on Methodology, one single action on each case page, and one compact control row on Glossary.
- Reuse existing rules, typography, controls, spacing, and semantic colors. No nested cards, dashboard styling, oversized panels, or decorative additions.
- All controls remain keyboard accessible and readable on narrow screens.

## Verification
- Check the Methodology audit sequence and reset at desktop and phone widths.
- Open a case, invoke the dossier print flow, and confirm print/PDF layout contains the complete briefing and sources without site navigation.
- Search, filter, and copy a glossary citation; verify the copied text and direct anchor link.
- Confirm the preview builds cleanly and produces no runtime or console errors.
